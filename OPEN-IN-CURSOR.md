# Ouvrir ce projet dans Cursor (UI locale)

## Chemin canonique

`C:\Users\Dell\Documents\freebox-dns`

## Option A — Open Folder (recommandé)

1. Cursor Desktop → **File → Open Folder…**
2. Coller / choisir : `C:\Users\Dell\Documents\freebox-dns`
3. Confirmer : l’explorateur affiche `README.md`, `docker-compose.yml`, `.git`

## Option B — Open Workspace File

1. **File → Open Workspace from File…**
2. Ouvrir : `C:\Users\Dell\Documents\freebox-dns\freebox-dns.code-workspace`

## Option C — Cursor Project / Workspace GitHub

1. Pousser ce dépôt sur GitHub (déjà fait si `gh` a réussi) : `https://github.com/dlnraja/freebox-dns`
2. Dans Cursor : **Project → Workspace** (ou équivalent) → sélectionner le dépôt GitHub `dlnraja/freebox-dns`
3. Pour travailler **en local**, clonez ou ouvrez le dossier Documents ci-dessus (même remote)

## Vérification rapide

```powershell
cd C:\Users\Dell\Documents\freebox-dns
git status
git remote -v
```

Le dossier Documents est la **racine canonique** à ouvrir dans l’app desktop.
