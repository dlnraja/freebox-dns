# Modèle de filtrage

## dns-libre

- Pas de blocklists.
- Amonts DoT / récursion orientés **non censure** (Quad9 unblocked, Digitale Gesellschaft, UncensoredDNS).
- Objectif : éviter les « DNS menteurs » opérateur / gouvernementaux.

## dns-secure

Listes **uniquement** :

- publicité / trackers
- malware / phishing

**Exclu volontairement :** listes de blocage politique, religieux, ou de censure nationale.

Sources typiques (rafraîchies par Blocky + CI) : StevenBlack hosts, AdAway, URLhaus, Spam404.
