Pi · VM · Windows DNS1 = votre IP DoH · DoT · hosts locaux

freebox-dns

Un résolveur DNS chez vous. Démarrez-le sur un Pi, une VM (Freebox ou autre) ou Windows — puis mettez son IP en DNS1 sur le routeur ou l’appareil.

Self-hosted LAN DNS. Freebox optional. Docker optional on Windows (native exe).

Règle DHCP / Wi‑Fi

Après health-check VM : DNS1 = 9.9.9.10 (Quad9 No Threat Blocking, sans ECS), DNS2 = IP de la VM. Le PC n'est pas le résolveur.
