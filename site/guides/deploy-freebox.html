Déploiement Freebox OS VM

Freebox OS n'importe pas d'OVA : il faut une image disque .qcow2 ARM64 (Delta / Pop / Ultra). Le package all-in-one inclut aussi un CD cloud-init.

Prérequis

  • Freebox Delta, Ultra ou Server v9+ avec rubrique VM
  • Artefact freebox-dns-freeboxos-allinone-*.zip (GitHub Actions → build-freebox-os-qcow2)
  • Accès FTP Freebox OS (dossier VMs/)
  • 2 vCPU · 2048 Mo RAM · réseau LAN
  • ARM64 uniquement — une image amd64 ne boote pas

Mode sûr — ne pas casser Internet

Connaissez le filet SOS avant tout déploiement. DHCP Freebox : DNS1 = 9.9.9.10, DNS2 = IP VM — seulement après health-check.

Guide DHCP sûr →

Import all-in-one (recommandé)

1

Télécharger l'artefact

GitHub → Actions → workflow build-freebox-os-qcow2 → artefact freebox-dns-freeboxos-allinone-*.zip.

Contenu : freebox-dns.qcow2, freebox-dns-cidata.iso, JSON, checksums.

2

Copier via FTP

Extraire le zip. Via FTP Freebox, créer VMs/ et y copier :

VMs/freebox-dns.qcow2
VMs/freebox-dns-cidata.iso
3

Créer la VM

Freebox OS → VM → Ajouter → image de disque existante → freebox-dns.qcow2.

  • 2 vCPU · 2048 Mo · LAN · OS debian
  • Monter freebox-dns-cidata.iso en CD-ROM virtuel
4

Démarrer et vérifier

Attendre 2–5 min (Docker + stack). Noter l'IP LAN.

dig @IP_VM example.com
dig @IP_VM -p 5354 doubleclick.net
bash scripts/health-check.sh
5

DHCP (après health uniquement)

DNS1 = 9.9.9.10 · DNS2 = IP VM. Ne jamais laisser la seule IP VM sans secondaire.

Déploiement API (optionnel)

python scripts/safe-freebox-vm-deploy.py auth
python scripts/safe-freebox-vm-deploy.py download
python scripts/safe-freebox-vm-deploy.py deploy

Paramètres VM typiques :

name=freebox-dns
vcpus=2
memory=2048
disk_type=qcow2
disk_path=<disque>/VMs/freebox-dns.qcow2
cd_path=<disque>/VMs/freebox-dns-cidata.iso
os=debian
enable_cloudinit=true
cloudinit_hostname=freebox-dns

Rebuild local

sudo apt-get install -y qemu-utils cloud-image-utils genisoimage zip curl
bash scripts/build-freebox-qcow2.sh
bash scripts/package-freebox-os-allinone.sh
