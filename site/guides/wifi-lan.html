Wi‑Fi / LAN

Le résolveur DNS = la machine qui fait tourner freebox-dns (Pi, VM Freebox, mini-PC Windows). Mettez son IP en DNS1 sur le routeur ou sur l’appareil.

Machine toujours allumée

Évitez un laptop qui dort comme DNS du salon. Pi / VM / mini-PC dédié. Windows natif : guide Windows.

Chaîne

Clients  →  Routeur DHCP (ou DNS manuel)
               DNS1 = IP_RESOLVEUR   (Pi / VM / Windows)
               DNS2 = 9.9.9.10      (SOS Quad9)
                    →
               freebox-dns (:53)

Configurer le routeur

  1. Réservez l’IP du résolveur (bail fixe).
  2. DHCP → DNS personnalisés : DNS1 = IP résolveur, DNS2 = 9.9.9.10.
  3. Sur Freebox OS : Paramètres → Mode avancé → DHCP (mêmes valeurs).
  4. Reconnectez le Wi‑Fi / ipconfig /renew.

Vérifier

Get-DnsClientServerAddress -AddressFamily IPv4
# Attendu : IP_RESOLVEUR puis 9.9.9.10

Resolve-DnsName example.com -Server IP_RESOLVEUR
# ou : dig @IP_RESOLVEUR example.com +short

Lab Docker sur PC

Ports 5356… = tests. Ne poussez pas cette IP en DHCP salon sauf mini-PC dédié en prod :53. Voir lab WSL.
