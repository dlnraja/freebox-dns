Wi‑Fi / LAN

Le résolveur DNS de votre salon = la VM freebox-dns sur la Freebox. Votre PC Windows est un client Wi‑Fi comme un téléphone.

Pas le PC

Ne mettez jamais l'IP de votre PC Windows dans le DHCP Freebox. Si le PC s'éteint, tout le Wi‑Fi perd le DNS.

Chaîne

Clients Wi-Fi  →  Freebox DHCP
                    DNS1 = 9.9.9.10   (SOS Quad9)
                    DNS2 = IP_VM     (ex. 192.168.1.71)
                         →
                    VM freebox-dns (hosts → Unbound → DoT)

Configurer Freebox OS

  1. Paramètres → Mode avancé → DHCP
  2. DNS personnalisés : DNS1 = 9.9.9.10, DNS2 = IP de la VM
  3. Sur les clients : reconnecter le Wi‑Fi ou ipconfig /renew

Vérifier depuis Windows

Get-DnsClientServerAddress -AddressFamily IPv4
# Wi-Fi doit lister 9.9.9.10 puis l'IP de la VM

# La VM répond ?
# dig @IP_VM example.com +short

Lab PC / WSL

Docker sur le PC = tests seulement. Voir guide WSL — ne pas pousser cette IP en DHCP.
