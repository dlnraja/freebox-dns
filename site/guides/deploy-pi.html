Déploiement Raspberry Pi

Image recommandée : Raspberry Pi OS 64-bit (Pi 4/5) ou Debian. Le Pi peut servir de résolveur LAN à la place d'une VM Freebox.

Prérequis

  • Raspberry Pi 4 ou 5 avec Pi OS 64-bit
  • Docker Engine + Compose v2
  • IP statique ou bail DHCP réservé dans Freebox OS
  • HOST_IP = IP eth0/wlan0 du Pi

Option A — cloud-init

1

Préparer l'image

Utilisez cloud-init/pi-user-data.yaml via Raspberry Pi Imager ou une image cloud-init : clone le dépôt, fixe HOST_IP, génère les certs, lance docker-compose.prod.yml.

Option B — installation manuelle

1

Installer Docker

curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker $USER
# Reconnecter la session
2

Cloner et configurer

git clone https://github.com/dlnraja/freebox-dns.git
cd freebox-dns
cp .env.example .env
# HOST_IP = IP eth0/wlan0 du Pi
bash scripts/generate-certs.sh
3

Lancer en prod

docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
bash scripts/health-check.sh
4

Configurer Freebox DHCP

Après health-check : DNS primaire = IP du Pi (dns-libre :53). Réservez le bail dans Freebox OS.

DoH : https://IP_PI:8453/dns-query (libre) · :8444 (secure).

Filet SOS recommandé

DNS1 = 9.9.9.10 (UncensoredDNS) · DNS2 = IP du Pi. Ne jamais une seule entrée DNS.
