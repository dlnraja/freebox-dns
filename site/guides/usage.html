Utilisation au quotidien

Configurer le LAN, les clients chiffrés (DoH/DoT), valider avec dig et consulter l'UI Blocky.

Prérequis

  • Stack démarrée et bash scripts/health-check.sh OK
  • HOST_IP connu (ex. IP VM typique 192.168.1.x — la vôtre peut différer)
  • Certificats DoH générés (scripts/generate-certs.sh)

DHCP Freebox (après health VM)

Filet SOS obligatoire

DNS1 = 9.9.9.10 · DNS2 = IP VM. Ne jamais une seule entrée.

URLs DoH

# dns-libre (uncensored)
https://HOST_IP:8453/dns-query

# dns-secure (filtrage Blocky)
https://HOST_IP:8444/dns-query

Générer les profils clients :

python3 scripts/generate-client-profiles.py

Fichiers dans config/clients/generated/ : Firefox policies, Apple mobileconfig, Android Private DNS, Windows PowerShell.

3

Par plateforme

  • iOS / macOS : installer apple-doh-libre.mobileconfig ou apple-doh-secure.mobileconfig
  • Firefox : policies JSON dans config/clients/generated/
  • Android : Private DNS = hostname seulement → utiliser Nebulo/Intra avec DoH, ou DoT :853 en prod
  • Windows : windows-doh.ps1 généré

Tests rapides

4

dig et curl

# Plain DNS (lab)
dig @HOST_IP -p 5356 example.com +short          # dns-libre
dig @HOST_IP -p 5354 example.com +short          # dns-secure
dig @HOST_IP -p 5354 doubleclick.net +short     # doit être bloqué/NXDOMAIN

# DoH
curl -sk "https://HOST_IP:8453/dns-query?name=example.com&type=A"
curl -sk "https://HOST_IP:8444/dns-query?name=example.com&type=A"

# Health global
bash scripts/health-check.sh
