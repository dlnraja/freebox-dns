Installation

Démarrage rapide pour Docker Desktop, WSL2 ou Raspberry Pi. Choisissez ensuite le guide de déploiement cible.

Prérequis

  • Docker Engine + Docker Compose v2
  • Ports libres (lab) : 5356 / 5354 (DNS), 8453 / 8444 (DoH), 3080 (UI Blocky)
  • En prod LAN : mappez 53 si rien d'autre ne l'occupe
  • HOST_IP = IP LAN de la machine Docker (bind local-only)
1

Cloner et configurer

git clone https://github.com/dlnraja/freebox-dns.git
cd freebox-dns
cp .env.example .env
# Éditer HOST_IP = IP LAN visible par la Freebox
2

Certificats DoH

# Linux / WSL / Pi
bash scripts/generate-certs.sh

# Windows PowerShell
powershell -File scripts\generate-certs.ps1
3

Lancer la stack (lab)

# Lab — ports 5356/5354 (Windows / WSL)
docker compose up -d

# Prod Freebox VM / Pi — DNS :53 sur HOST_IP
docker compose -f docker-compose.yml -f docker-compose.prod.yml up -d
4

Vérifier la santé

bash scripts/health-check.sh

dig @HOST_IP -p 5356 example.com +short    # dns-libre
dig @HOST_IP -p 5354 example.com +short    # dns-secure
curl -sk "https://HOST_IP:8453/dns-query?name=example.com&type=A"

Avant de toucher au DHCP Freebox

Ne modifiez le DHCP qu'après un health-check OK. Filet SOS : DNS1 = 91.239.100.100, DNS2 = IP VM.
