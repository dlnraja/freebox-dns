DHCP sûr — ne jamais casser le LAN

Ce guide décrit le filet de sécurité DNS avant et pendant le déploiement d'une VM freebox-dns. La règle d'or : ne touchez pas au DHCP tant que la stack n'est pas saine.

Configuration SOS recommandée

PrioritéIPService
DNS19.9.9.10Quad9 Unsecured (SOS UDP)
DNS2HOST_IPVM / Pi freebox-dns

Si la VM tombe, le LAN continue via Quad9 Unsecured. Si la VM répond, elle sert dns-libre en DNS2 — toujours deux entrées.

Avant de modifier le DHCP

  • dig @IP_VM example.com retourne une réponse valide
  • bash scripts/health-check.sh passe sans erreur
  • Vous connaissez le filet SOS ci-dessus
  • Vous avez noté l'IP LAN stable de la VM (bail réservé recommandé)

Filet SOS étendu (dépannage)

En cas de panne DNS grave, vous pouvez basculer temporairement sur trois pins publics :

PrioritéIPNom
19.9.9.10Quad9 Unsecured
2194.242.2.2Mullvad Unfiltered
394.140.14.140AdGuard Non-filtering
 
# Afficher le filet SOS
python scripts/safe-freebox-vm-deploy.py sos

# Appliquer via API Freebox (après auth locale)
python scripts/safe-freebox-vm-deploy.py auth
python scripts/safe-freebox-vm-deploy.py dhcp-sos

Phases de déploiement sûr

1

SOS — connaître le filet

Mémorisez les pins avant toute action. Ne modifiez pas le DHCP Freebox pendant l'import VM.

2

Auth API locale

python scripts/safe-freebox-vm-deploy.py auth

Validez sur l'écran Freebox. Ne commitez jamais .freebox-token.json.

3

VM — import et boot

Télécharger QCOW2, copier FTP, créer VM, monter cloud-init ISO, démarrer. Voir guide Freebox.

4

Health — valider la stack

dig @IP_VM example.com
bash scripts/health-check.sh
5

DHCP — seulement après health

DNS1 = 9.9.9.10 · DNS2 = IP VM. Double-check avant d'appliquer.

Interdit

  • Remplacer le DHCP par la seule IP VM sans secondaire
  • Modifier le DHCP avant health-check OK
  • Committer des tokens Freebox ou numéros de série
  • Automatiser une relecture distante de votre Freebox depuis le CI

Les 5 pins épinglés (FREEBOX_DNS_1..5)

Capturés une fois depuis le LAN — jamais re-interrogés à distance :
